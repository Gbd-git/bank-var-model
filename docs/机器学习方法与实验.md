# 机器学习 VaR：四类八个代表模型

本次新增核分位数回归、分位数森林、分位数直方图提升树、MLP、LSTM、GRU、TCN与Transformer。它们覆盖前四类机器学习方法，不包含概率分布学习、混合专家或GARCH修正模型。没有把LightGBM、XGBoost和CatBoost的不同库实现全部重复加入；提升树以sklearn直方图分位数提升树作为本次代表。

## 统一样本与预测时点

沿用原数据4575条、14家银行，初始2000条之后的2575条评分，滚动标签窗口1500条，每5条重新拟合/更新。99%与95%损失VaR对应收益1%与5%下尾分位数，损失VaR为收益分位数的相反数。输入及指标单位均为百分数对数收益。逐银行违背率、pinball loss与覆盖检验公式见[统计方法与评价](方法与评价.md)。数据来源和缺口沿用原文件，不另行补齐。

每个预测日期t的解释变量仅依赖t之前收益。一次重估后的5条预测可以用同一组参数逐条计算；每条预测的特征只读取它之前的数据，不能把5条收益提前用于拟合。代码虽向量化生成这些特征，但改变未来收益的因果回归检查用于验证该信息边界。

## 输入与标准化

表格输入共28维：最近20条收益（从近到远），过去5/20/60条的均值和样本标准差，过去20条负收益平方均值，以及上条收益绝对值。序列输入为最近20条的收益及绝对收益两个通道（从远到近）。因此，最早训练行的特征会访问窗口前至多60条已知历史，不是未来数据。

表格特征均值/标准差、每银行收益均值/标准差只在初始训练窗口[500,2000)估计，以后冻结。收益目标标准化为z=(r-mu0)/sigma0；序列两个通道除以sigma0。输出通过q_r=mu0+sigma0*q_z还原后评分。零方差尺度下限1e-6。没有在全部评价数据上拟合标准化器。

银行之间不共享训练数据、特征或可学习参数。神经网络利用张量的银行维向量化计算，但权重、偏置、梯度裁剪和Adam状态都按银行独立；LayerNorm只作用于单个样本的特征维。每家网络的两个分位数共享该银行内部表示。

## 核方法：Nyström-RBF分位数回归

使用k(x,c)=exp(-gamma*||x-c||²)，gamma=1/28。初始训练窗口中以固定随机种子选择32个基点，构造Phi(X)=K(X,C)K(C,C)^(-1/2)，特征值下限1e-12，之后基点与映射冻结。每个滚动窗口求解：

$$\min_{b,w}\sum_{s\in\mathcal W_t}\rho_\tau(z_s-b-\phi(x_s)'w)+0.5\|w\|_1.$$

截距不惩罚；使用HiGHS求解对偶LP：最大化z'u，约束sum(u)=0、|Phi'u|<=0.5、tau-1<=u<=tau。原始与对偶目标值另行核对。

**这是带L1正则的近似核分位数回归，不是完整核矩阵、L2/RKHS正则的Quantile SVR。**它作为核方法类的一个明确代表；不能将其结果直接写成所有SVR方法的表现。

## 树模型

分位数森林使用32棵随机特征森林树，最大深度5、叶节点至少50条、max_features=0.5、bootstrap=False。无bootstrap时依靠逐分裂随机特征子集产生树间差异；这是明确指定的QRF实现规格。树以平方误差准则分裂，但预测使用完整叶内收益经验分布：

$$w_s(x)=\frac1B\sum_{b=1}^B\frac{\mathbf1\{x_s\in L_b(x)\}}{\#\{j:x_j\in L_b(x)\}},\quad \widehat F(y\mid x)=\sum_s w_s(x)\mathbf1\{z_s\le y\}.$$

预测取加权经验CDF的广义逆，不是树均值预测的分位数。森林内部4线程，其他BLAS线程限制为1。每次重估冷启动。

分位数提升树使用HistGradientBoostingRegressor，分别拟合两个tau；loss=quantile、40轮、最多7叶、叶至少40条、最多32个直方图区间、学习率0.05、L2=1。禁用自动早停，以免默认随机切分验证集；每次重估冷启动。这里的训练轮数是固定预算，未声称达到最优迭代数。

## 神经网络

所有网络联合最小化两个分位水平的平均pinball loss；不使用MSE均值预测冒充VaR。随机种子20261113、CPU计算、确定性算法。输出层权重初始为0，偏置设为初始训练收益的经验分位数，以提供合理的尾部起点。

| 模型 | 网络规格 |
| --- | --- |
| MLP | 28维输入，24/12两层tanh，两个输出 |
| LSTM | 单层12隐藏单元，遗忘门偏置加1，最后隐藏状态输出 |
| GRU | 单层12隐藏单元，重置门作用于候选状态的循环投影，最后状态输出 |
| TCN | 12通道，核宽3，膨胀率1/2/4的三层因果残差卷积；有效感受野15条 |
| Transformer | 12维、3头、单编码块，24维前馈层、固定正弦位置编码、因果mask，无dropout；LayerNorm无可学习仿射参数 |

LSTM/GRU每个20条输入窗口的隐藏状态从零开始，不跨预测窗口保留隐状态。TCN和Transformer也只读取当前历史输入窗口。上述网络为本项目的小规模可复现实现，结构见code/ml_networks.py，不声称复现某篇论文的全部超参数。

Adam学习率0.001、weight_decay=1e-5、每银行梯度范数裁剪5；batch=128。首次训练200个随机小批量步，之后每5条收益继续12步。每一步均从当前1500条标签窗口有放回抽样。有限小批量步不保证每次遍历全部训练行，也不保证优化收敛；完整预测期的全部日期均被评分，没有删除评价样本。

模型参数和Adam状态热启动，因此可能保留窗口之前学习的历史信息。它不是每次从零训练的严格滑动窗口网络，也不是每条收益都更新参数的流式版本。与统计模型比较时，应将这种训练机制差异纳入解释。

## 分位数交叉与指标

两个输出可能交叉。与原项目一致，对输出按分位水平排序后评分与绘图；同时保存raw_predictions.npy、predictions.npy与交叉计数。排序不是针对当期真实收益做的事后选择，不使用标签决定顺序。

每模型提供14家银行的VaR时序图，以及违背次数/率、pinball loss、Kupiec/独立性/条件覆盖检验。总体指标对相同银行日期等权平均。计算时间是整个模型拟合与预测的墙钟时间，不含指标导出、绘图与报告；包括特征构造、首次导入/初始化等。统计和机器学习的并行负载不同，森林还使用内部4线程，不能把一次耗时比当成严格复杂度结论。

## 研究解释与限制

配置按模型定义与计算预算设定，未根据完整评价期损失调参；本次没有独立的超参数搜索，不能声称这些是开发集选出的最佳配置。不同模型优化预算并不等价。仅一个随机种子，没有报告多种子置信区间、统计显著性排名或模型置信集。

1500条窗口中1%尾部对应约15条观测，尾部监督信号较少。增加网络复杂度并不保证精度更高。该历史评价段过去已被使用，若要形成论文最终结论，还需独立时间保留集、训练预算敏感性、多种子和危机子样本稳健性分析。
