# 方法分类、统一回测与评价

## 1. 范围与可比性

六类17个具体模型是本次选定的代表规格，不是列举每个模型族的所有可能变体。历史模拟重复项已合并。蒙特卡洛是计算方式，可与多种分布结合；本包选用静态高斯和静态Student-t两个明确的情景生成模型。GARCH模型本身也属于参数模型，分类仅为方便组织。

每家银行分别预测其自身股票收益，不合并成投资组合，不计算CoVaR、MES或银行间传染。本包延续之前的滚动重估版本，不是逐样本Adam参数更新版。

输入为 $r_t=100\log(1+\mathrm{pctChg}_t/100)$，单位是百分数对数收益。每条记录预测下一条保留记录的收益下尾分位数 $q_{\tau,t}$，$\tau\in\{0.01,0.05\}$；损失VaR为 $-q_{\tau,t}$。图中绘制收益及负向阈值，CSV同时提供损失VaR。数据缺口导致“单期”不能全部解释为相邻交易日。

共同数据4575×14；前2000条为初始化/开发段，后2575条评分。估计窗口 $\mathcal W_t=\{t-1500,\ldots,t-1\}$；每5条重估。当天收益只能在预测保存后进入下一步状态更新。静态分布和HS在非重估日保持预测不变；GARCH/CAViaR更新递归状态，线性QR更新滞后解释变量。各方法使用同一重估频率，但信息响应机制不同；本比较不声称这消除了所有结构差异。

## 2. 历史模拟与静态参数法

HS直接取窗口经验分位数。高斯参数法使用MLE均值与标准差：

$$q_{\tau,t}=\widehat\mu+\widehat\sigma\Phi^{-1}(\tau).$$

静态Student-t对位置、尺度与自由度进行数值MLE：

$$q_{\tau,t}=\widehat\ell+\widehat s\,t_{\widehat\nu}^{-1}(\tau).$$

这里 $s$ 是尺度，不是标准差；静态t拟合未强制 $\nu>2$。高斯标准差为ddof=0。数值拟合不等于证明找到了全局MLE。

## 3. 蒙特卡洛

分别按以上两个静态分布拟合后，每银行每重估生成20,000条收益情景并取经验分位数；种子20261113。模拟结果在接下来5条记录内沿用。解析版本和MC版本的理论分布相同，结果差异来自模拟积分误差。这里只计算单期收益，不模拟多期复利路径，也不引入银行间相关性。单种子不足以量化Monte Carlo误差分布。

## 4. GARCH家族

$$r_t=\mu+\sqrt{h_t}z_t,$$
$$h_t=\omega+\alpha\epsilon_{t-1}^2+\gamma\mathbf1\{\epsilon_{t-1}<0\}\epsilon_{t-1}^2+\beta h_{t-1}.$$

GARCH令 $\gamma=0$，GJR-GARCH估计额外非对称项。分别搭配标准高斯、标准化t、Hansen标准化skew-t，得到六种规格。

$$q_{\tau,t}=\widehat\mu+\sqrt{\widehat h_t}\,F_{\widehat\psi}^{-1}(\tau).$$

t创新采用单位方差参数化，$F^{-1}(\tau)=\sqrt{(\nu-2)/\nu}\,t_\nu^{-1}(\tau)$，$\nu>2$。Skew-t不是普通t的平移；它使用Hansen标准化形式。估计调用arch的常数均值、p=1、q=1、o=0或1、rescale=False，参数边界与约束沿用该库，不额外宣称估计满足所有理论平稳性假设。

首次冷启动，之后以上次参数热启动，最多500次迭代；不收敛则冷启动最多1500次。仍失败时沿用该银行上次参数与当前递推状态，首次失败直接停止。所有失败记录保留，不删评价日期。原GJR-GARCH-skewt实现未改动，其他规格独立拟合；两次重估之间参数固定、方差逐条更新。

## 5. EVT与半参数方法

对损失 $L=-r$ 取窗口90%经验阈值 $u$，超额 $L-u\mid L>u$ 拟合位置固定0的GPD，实际超额比例为 $p_u$：

$$q_\tau=-\left[u+G_{\xi,s}^{-1}\left(1-\frac{\tau}{p_u}\right)\right].$$

POT-GPD直接对收益尾部拟合；GARCH-t-EVT先拟合GARCH-t，再对负标准化残差拟合GPD并按当期预测波动还原。后者的最终尾部分布来自GPD，不是继续使用t尾部。每窗口至少需要50个超额；若后续拟合无效，记录并沿用上一有效估计；首次无效报错。

GARCH-t-FHS同样先过滤波动，但使用标准化残差的经验分位数，不拟合GPD。对单期经验分布直接取分位数等价于求其经验分布阈值，无须额外bootstrap抽样。

阈值90%固定，未根据评价段挑选；本包尚未做85%/95%阈值敏感性研究。GPD有限阈值近似及尾部参数稳定性不由一次成功拟合保证。

## 6. 条件分位数模型

CAViaR-SAV：

$$q_{\tau,t}=b_0+b_1q_{\tau,t-1}+b_2|r_{t-1}|.$$

CAViaR-AS：

$$q_{\tau,t}=b_0+b_1q_{\tau,t-1}+b_2r_{t-1}^{+}+b_3(-r_{t-1})^{+}.$$

分别按两个水平最小化窗口pinball。$b_1\in[0,0.995]$、$b_0\in[-20,20]$、收益项斜率在[-5,5]；窗口最初250条经验分位数初始化状态，前25条用于递归预热，不进入拟合损失。使用两组固定起点及上次参数热启动，带解析次梯度的L-BFGS-B，最多300次迭代，取有限目标值最小者。有限但未收敛的解会记录；该实现属于有明确边界的CAViaR规格，不保证全局最优或复现原论文优化器。

线性QR定义：

$$x_t=(1,r_{t-1},|r_{t-1}|,\mathrm{sd}(r_{t-20},\ldots,r_{t-1}))',$$
$$\widehat b_\tau=\arg\min_b\sum_{s\in\mathcal W_t}\rho_\tau(r_s-x_s'b),\qquad q_{\tau,t}=x_t'\widehat b_\tau.$$

使用等价对偶线性规划HiGHS求解，无系数符号约束：最大化 $r'u$，约束 $X'u=0$ 及 $\tau-1\le u_s\le\tau$。计算时最小化其负值，并由等式约束的对偶边际量取负得到回归系数。这样将原始问题的1500个等式约束减少为4个，估计目标不变。最早训练行的特征需要读取窗口之前已知的20条收益；这些不是未来数据。

独立估计的分位数可能交叉。所有模型统一按分位水平排序用于报告；保存 `raw_predictions.npy` 与交叉计数。CAViaR内部继续递推未排序的各自分位状态，排序仅用于输出，避免改变模型递推方程。

## 7. 评价指标

$$\rho_\tau(u)=u(\tau-\mathbf1\{u<0\}),\qquad \overline L_\tau=\frac1{14T}\sum_{i,t}\rho_\tau(r_{i,t}-\widehat q_{\tau,i,t}).$$

$$I_{\tau,i,t}=\mathbf1\{r_{i,t}<\widehat q_{\tau,i,t}\},\qquad \widehat p_{\tau,i}=T^{-1}\sum_t I_{\tau,i,t}.$$

Pinball越低越好；违背率应接近1%/5%，过低可能是过度保守，不能据此判为更准。每个银行及水平提供违背次数、违背率、平均pinball、Kupiec无条件覆盖、Christoffersen独立性及条件覆盖p值。

Kupiec统计量为名义Bernoulli似然与经验违背率似然的 $2\log$ 比。独立性检验比较一阶二状态Markov转移似然与单一违背概率似然；条件覆盖统计量为二者之和，分别采用1、1、2自由度卡方渐近参考分布。$0\log0$ 取0；稀少违背会削弱渐近近似。仅逐银行计算p值，不把跨银行相关样本合并成独立Bernoulli样本。未做多重检验校正。

总体表是同日期银行等权平均，不是系统损失分布的VaR。本文没有做配对区块bootstrap、Diebold-Mariano或模型置信集检验，因此数值排名不能写成“统计显著最优”。

## 8. 可重复性与限制

预测因果顺序由代码检查；数据与原发布包一致。评价段曾用于以往研究，不能当作从未查看的独立测试集。原始来源存在日期筛选、停牌填零与价格链差异，见data/README.md，未为了模型排名修改数据。

每模型summary保存耗时、配置、种子、数据SHA256、拟合事件和GPD拟合参数；运行耗时包含多进程竞争与JIT预热，不能直接声称某模型严格快多少倍。正式速度比较应在固定硬件、单进程、统一编译计时政策下重复测量。
