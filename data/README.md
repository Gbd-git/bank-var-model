# 数据集说明

来源：项目已归档的 BaoStock 银行日行情；此包是本地数据快照，没有重新下载或修改供应商数据。

计算输入 y = 100 * log(1 + pctChg/100)，-1 表示 -1%的对数收益。原始收益宽表单位为小数，计算输入乘100。不要直接将后复权 close 的差分替换现有目标。

bank_returns.npz/csv 含4575行、14家银行；source_returns.csv 原宽表4622行。当前实验使用原研究的共同日期筛选结果；重现此实验应使用计算输入的日期表，不是重新把全部原始行情拼接后计算。起止日期内26条源日期未纳入，见 omitted_source_dates.csv；相邻记录不是必然相邻交易日，缺口收益未自动累计。

宁波银行2021-11-24、25、26、29、30和12-01的 pctChg 缺失，已在原数据处理时填为零。平安银行2020-12-31后复权价格链与 pctChg 存在来源内差异，本输入采用 pctChg 对应约+0.72655%的对数收益，未采用价格链约-17.6854%的变化。见 return_construction.csv。保留这些历史处理以复现既有实验，未静默修补。

默认前2000条为初始化/开发段，其余2575条评分。raw 下保留来源行情；不含账户、凭证或私人交易记录。银行股票收益不等同银行资产负债表损失。

本数据快照与已有实验输入一致；来源版本一致并不证明供应商数值完全正确。
